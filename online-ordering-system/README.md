# Online ordering practice demo

**Not the historical Potstickers order path.** Family restaurant work lives in [pstickers24](https://github.com/jadexzhao/pstickers24): customer HTML, a Google Site, Clover for orders, and Formspree for contact. See the [Potstickers case note](https://jadexzhao.github.io/jadexzhao/potstickers.html).

This folder is a later React / Express starter I used for practice. It is not a production ordering platform.

## What is in the source

- `src/App.tsx`: title and one sentence
- `backend/src/index.ts`: Express `/api/health` only
- Vite + Tailwind scaffolding

There is no menu, cart, checkout, payments, email, delivery logic, or admin dashboard in this repository.

## Status

Practice scaffold. Kept for local learning, not as proof of the 2019 to present restaurant system.

## Run the starter (optional)

```bash
npm install
npm run dev
```
