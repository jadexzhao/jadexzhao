# Digital Humans research question (sample note)

A public, high-level note for retrieval tests. No lab data, no
clinical framing, no grant numbers.

## The question

When an AI system looks and communicates like a person, what actually
makes people want to use it, trust it, and keep using it?

## Words that belong with that question

Trust, disclosure, anthropomorphism, user expectations, adoption,
human oversight, accountability, privacy, and usability.

## What this note does not contain

It does not name a launch, a user count, or a client deployment.
If a question asks for those, the notes do not have the answer.
