How I build

  • Start from the task a real person has to finish

    Nashville residents pay a bill, start water, or find a meeting. I map checks to WCAG so a recommendation is specific enough to act on.

  • Write the work so someone else can run it

    Serve IT: a Planner board with a name on each card, a sprint plan, and a stakeholder agenda. matchaxmoxie handoffs say what staff may change and what they should not.

  • Ship the smallest stack that survives Tuesday

    Potstickers is HTML, a Google Site, and Clover ... not a framework only I can deploy. Benyue was four React pages, not an extra layer I cannot prove.
