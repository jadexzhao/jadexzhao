How BM25 ranks my markdown notes

I wrote a 70-line Okapi BM25 ranker in Python with no packages. It lowercases text, keeps [a-z0-9]+ tokens, and scores each note by rare words that actually appear there. A word that shows up in every file barely helps. A long file does not automatically win.

I ran this from bm25-notes-search/ on 30 October 2026: 

python3 search.py . "tokenize index rank markdown" --top 3
# Indexed 1 markdown file. Top hit: README.md, score 1.222

That folder only has one .md file, so the ranking is honest and a bit dull. The interesting part is that you can read every line that produced the score.
