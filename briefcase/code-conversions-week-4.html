Snippet 3 · read grades.txt line by line · strip()

Week 4 · snippet 03

If the embed is blocked, open the shared Drive file: codeconv_w4_snippet03_jadezhao.mp4.

Try it · read the code

with open("grades.txt") as file:  # no mode > same as "r"
    # Scratch: forever for each line in the list
    for line in file:  # one line at a time · includes trailing \n until you strip
        # Scratch: say (line with edges cleaned)
        print(line.strip())  # strip() peels spaces/newlines off both ends · cleaner print
# predicted: each grade on its own line, no blank gap from leftover \n

Snippet 5 · count lines in reminders.txt

Week 4 · snippet 05

If the embed is blocked, open the shared Drive file: codeconv_w4_snippet05_jadezhao.mp4.

Try it · read the code

with open("reminders.txt", "r") as file:
    # Scratch: set [count v] to (0)
    count = 0  # accumulator box starts empty-zero
    # Scratch: forever for each line
    for line in file:  # each pass = one line (even a blank line counts)
        # Scratch: change [count v] by (1)
        count += 1  # 0>1>2>... once per line
print(count)  # predicted: how many lines were in the file (an integer)

Concept cards

  • Scratch: set [count v] to (0) · forever for each line · change count by 1 · say (count)
  • (W3Schools · For Loops · File) (Quizlet · for line in file) search YouTube: "Python count lines in file beginners"
  • Scratch: open reminders look-only
  • Scratch: set [count v] to (0)
