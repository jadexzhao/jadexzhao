num = 3  # whole number in a box
# ** means "times itself that many times" ... 3 ** 2 is 3×3 = 9, not "3 times 2"
# f"..." = f-string; {} drops the expression's value into the text (join metaphor)
print(f"{num} squared is {num ** 2}")  # predicted: 3 squared is 9

Snippet 6 · string clean-up, case, indexing, length

Week 1 · snippet 06

If the embed is blocked, open the shared Drive file: codeconv_w1_snippet06_jadezhao.mp4.

Try it · read the code

#          say (lowercase of cleaned), say (letter 1 of cleaned), compare length of cleaned vs greeting.

greeting = "  Hello there  "  # original has blank bits at both ends
cleaned = greeting.strip()  # trim ends only; middle stays; cleaned still has capital H
print(cleaned.lower())  # lower only happens inside this print → hello there
print(cleaned[0])  # index 0 = first character of cleaned (not lowercased) → H
print(len(cleaned) == len(greeting))  # cleaned is shorter → False (W3: len() = length of string)

Concept cards

  • Scratch: set [greeting v] to [ Hello there ], set [cleaned v] to (trim ends),
  • search YouTube: "Python string strip lower len" (or Corey Schafer · Strings)
  • Scratch: set [greeting v] to [ Hello there ] ... blank bits on both ends
  • Scratch: set [cleaned v] to (trim edge spaces of greeting)

Snippet 8 · input(), types, naming rules (bugs are intentional)

Week 1 · snippet 08

If the embed is blocked, open the shared Drive file: codeconv_w1_snippet08_jadezhao.mp4.

Try it · read the code

fav_num = input('What is your favorite number?' )  # input() always returns a string
# wait ... can a Scratch variable name start with 2? (no ... illegal name)
# is * on text costumes the same as doubling a number? (no ... need int() first, then * 2)
# Scratch brain for a fix: set [num v] to (answer as number), then set [doubled v] to (num × 2)
2num = fav_num * fav_num

# if this line ever ran with "14", string + would make "1414", not 28
print('Your favorite number doubled is:', fav_num + fav_num)

Concept cards

  • Scratch: ask [What is your favorite number?] and wait → set [fav_num v] to (answer).
  • search YouTube: "Python input() returns string" · "convert string to int Python beginners"
  • Scratch: ask [What is your favorite number?] and wait
  • Scratch: say (join of fav_num + fav_num) ... string + glues text, does not add numbers
