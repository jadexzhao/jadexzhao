Snippet 1 · if / elif / else grade ladder

Week 2 · snippet 01

If the embed is blocked, open the shared Drive file: I211-W2-CodeConvo-01-grade-if-elif-else.mp4.

Try it · read the code

grade = 84  # box labelled grade holds 84 (the score we will test)
if grade >= 90:  # is 84 at least 90? no → skip this whole block
    # Scratch: say [A]
    print("A")  # only runs if the if test was True
elif grade >= 80:  # is 84 at least 80? yes → take this branch
    # Scratch: say [B]
    print("B")  # predicted: this is what runs → prints B
else:
    # Scratch: say [C]
    print("C")  # would run only if grade was under 80

Snippet 4 · try / except / finally

Week 2 · snippet 04

If the embed is blocked, open the shared Drive file: I211-W2-CodeConvo-04-try-except-finally.mp4.

Try it · read the code

try:  # start the "attempt this" bubble
    # Scratch: say (10 ÷ 0) ... divide by zero crashes in real maths and in Python
    print(10 / 0)  # ZeroDivisionError here · never finishes this print
except ZeroDivisionError:  # only catches divide-by-zero, not every error in the world
    # Scratch: say [Cannot divide by zero]
    print("Cannot divide by zero")  # safety message instead of a red traceback
finally:
    # Scratch: say [Done]
    print("Done")  # predicted order: Cannot divide by zero · then Done

Snippet 5 · while loop, step +2

Week 2 · snippet 05

If the embed is blocked, open the shared Drive file: I211-W2-CodeConvo-05-while-count-by-2.mp4.

Try it · read the code

i = 0  # loop counter box
while i < 5:  # first check: 0 < 5 True · later 2 < 5 True · 4 < 5 True · 6 < 5 False stop
    # Scratch: say (i)
    print(i)  # predicted prints: 0 · then 2 · then 4
    # Scratch: change [i v] by (2) ... must move the counter or you loop forever
    # eli5: += 2 means "take whatever i is, add 2, put it back in i"
    i += 2  # 0→2 · 2→4 · 4→6 ... then while test fails and we leave

Concept cards

Snippet 7 · for letter + break

Week 2 · snippet 07

If the embed is blocked, open the shared Drive file: I211-W2-CodeConvo-07-for-break-cat.mp4.

Try it · read the code

for letter in "cat":  # letter is a temporary box for the current character
    # Scratch: if <(letter) = [a]> then
    if letter == "a":  # compare: is this letter exactly "a"? (== asks, = would set)
        # Scratch: stop this loop (leave early)
        # eli5: break = leave the for loop right now · do not finish the rest of "cat"
        break  # on "a": exit loop before print · "t" never visited
    # Scratch: say (letter) ... only if we did not break
    print(letter)  # predicted: only "c" prints (a breaks · t never reached)

Concept cards

  • Scratch: for each letter of [cat] · if letter = a then stop · else say letter.
  • (W3Schools · For Loops · Break) (YouTube · Corey Schafer · For loops)
  • search YouTube: "Python for loop break beginners"
  • Scratch: for each [letter] of [cat]
