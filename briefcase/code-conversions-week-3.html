Snippet 5 · stats · multiple return values (tuple)

Week 3 · snippet 05

If the embed is blocked, open the shared Drive file: codeconv_w3_snippet05_jadezhao.mp4.

Try it · read the code

# Python packs them into a tuple (ordered pair).

def stats(a, b):
    total = a + b  # 8 + 3 → 11
    difference = a - b  # 8 - 3 → 5
    return total, difference  # return two values → becomes a tuple

result = stats(8, 3)  # result type: tuple · like (11, 5)
print(result)  # predicted output: (11, 5)
