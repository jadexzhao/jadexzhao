# Full-stack practice scaffold

Practice starter for a React and Express layout. It is not a production-ready component library and not a human-AI product.

## What is in the source

- `src/App.tsx`: heading and one sentence
- `server/src/index.ts`: Express `/api/health` only
- Vite + Tailwind scaffolding

There is no WCAG-tested component set, JWT authentication, PostgreSQL, Prisma, Docker Compose, Storybook, or test suite in this repository.

## Status

Learning scaffold. Useful as a folder shape, not as evidence of shipped modules.

## Run the starter (optional)

```bash
npm install
npm run dev
```
